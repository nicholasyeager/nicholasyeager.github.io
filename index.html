SocraticAI

A chatbot built around Socratic questioning, helping users explore ethical and philosophical reasoning through conversation.

A React chat interface connects to local models through Ollama, with a Node.js / Express backend and MongoDB for conversation history and thematic progression.

Why local models? +

Running the model locally supports private, offline reasoning. Persistent conversation history lets the application carry a line of inquiry across sessions.
