# Nicholas Yeager’s personal website

A static portfolio hosted on GitHub Pages. No framework, build step, or runtime dependencies.

Open `index.html` directly to preview, or serve this directory with any static HTTP server. The main page uses `styleMain.css` and `scriptMain.js`.

Content updated in September 2026 from Yeager-Resume.pdf: Everpure internship, University of Alabama research, education, and selected projects. Personal interests and photographs are retained from the original site.

To update the resume, replace `Yeager-Resume.pdf`. Edit the dated note in the introduction when updating the page. Expandable project and experience notes work without JavaScript. The original Google Analytics property is preserved.

The separate `pricingCard.html` exercise and its assets are retained from the original repository.
